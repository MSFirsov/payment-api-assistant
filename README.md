# payment-api-assistant

Проект помощника по документации вымышленного платёжного API.

После урока 1 проект читает `docs/payments.md`, нарезает его по заголовкам и делит длинные разделы по абзацам. Каждый фрагмент хранит текст, имя файла, путь раздела и ID. Команда в терминале показывает, например, комиссию за платёж картой `2,4%` из раздела `Платежи -> Комиссии` файла `payments.md`.

## Запуск

Из корня проекта с Python 3.14 и `uv` выполни:

```bash
uv sync --locked
uv run payment-api-assistant
uv run pytest -q
```
